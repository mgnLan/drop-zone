# ПАК «ПОЛИРОВКА v1» — ПОЛНЫЙ, ФИНАЛЬНЫЙ

17 блоков одним прогоном, без остановок и без вопросов создателю — спорные
решения принимай сам как геймдизайнер и верни список принятых решений в отчёте.

Анкор дизайна: фон #05070c–#0b1428, акценты #ff3c6e (роза) и #28d8ff (циан),
плёнка 0.68.

## БЛОК 1. СВЕТ АРЕНЫ
arena3d.gd (~2949–3050): угловые споты 8.0→4.5, центральный 10.0→6.0,
луна 0.9→0.55, эмбиент 0.75→0.45, glow 0.45→0.28, bloom 0.1→0.05,
fog 0.005→0.008. `_apply_cinematic_env` — те же −40%. Телеграфы, подсветку
клеток и вспышки выстрелов НЕ трогать.

## БЛОК 2. ВЕРТИКАЛЬ ОКНА
Прод-обёртка: `height: Math.min(vh,720)`, `height2: Math.min(vh2,720)`,
`width: Math.min(vw,1000)` — только `vk_platform=desktop_web`; при
`window.dzFs` (fullscreen из arena3d.gd ~7576) кап не применять.

## БЛОК 3. ЦВЕТ ПОЛЕЙ KEEP
В `_ready()`: `RenderingServer.set_default_clear_color(Color("#edeef0"))`.

## БЛОК 5. ЕДИНАЯ СИСТЕМА КНОПОК
Баг: при hover ценовая кнопка обрезает последнюю цифру и уходит в серый —
причина autoshrink + hover без явного цвета. Фикс: min_size по тексту,
Theme Override без autoshrink, hover с явными цветами.
Стиль «Перелив»: фон градиент #141824→#0d1220, текст #f2f6ff; рамка 1.5 px,
по ней циклически (2.4 c, по часовой) бежит градиент #ff3c6e→#28d8ff→#ffd166;
после прохождения блика в правом верхнем углу ✦ мерцает дважды
(alpha 0→1→0.3→1→0, 0.9 c, пауза до цикла).
Hover: подложка акцента 12%, рамка ярче, текст и размер не меняются.
«Выбрано»: заливка #28d8ff33, бордер #28d8ff, перелив стоит.
Приоритетные (В БОЙ, Найти бойца, Купить): + заливка #ff3c6e→#ff7a45,
белый текст. Плоский красный (#c0392b) и оранжевый кассы (#f39c12) — убрать везде.

ЛЕВЕЛ-АП В БОЮ (новое правило, сейчас баг): во время боя новый уровень даёт
ТОЛЬКО очки характеристик (распределение сразу), HP и ОД НЕ восстанавливаются;
полное восстановление HP до максимума нового уровня — только ПОСЛЕ боя на
экране итогов; ОД от левел-апа не восстанавливаются никогда — только штатно
по ходу. Тост: «Уровень N! Очки +K — распределим после боя, HP восстановится
после боя».
