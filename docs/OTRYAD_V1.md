# МИНИ-ПАК «ОТРЯД v1» — компактность экрана отряда (принято создателем)

Скрины: узкое окно, экран «Отряд — создание бойцов». Проблемы:
(1) скроллбар висит посередине экрана («квадрат»), (2) палитры
«Кожа/Камуфляж/Скин» срезаны границей колонки, (3) всё не влезает
без прокрутки.

## 1. Скрыть скроллбары колонок
sc_l / sc_r (ScrollContainer, ~стр. 10821/10831): стилизовать VScrollBar —
modulate alpha 0.0 (прокрутка колесом/свайпом работает, полоса не видна).
Либо заменить контейнеры на обычные VBox, если после п.2 прокрутка
не нужна вовсе — тогда скроллбары убираются сами.

## 2. Всё влезает без прокрутки (десктоп 914×570)
- Доступная высота колонок: `area_h = clampf(_vh() - 340, 220, 700)` →
  `_vh() - 240` (заголовок+вкладки занимают меньше);
- Строки внешности (Ник/Оружие/Класс/Герой/Пол): шрифт 14 → **12 px**,
  отступы между строками −30 %;
- Свотчи «Кожа»: 24 → **20 px**; чипы «Камуфляж/Скин»: 30 → **26 px**,
  шрифт чипов 12 → **11 px**;
- Панель статов: separation 6 → **4**, строка статов шрифт 15 → **13 px**,
  подписи эффектов «+2% веса…» 12 → **11 px**;
- «Переподготовка», «Таланты», заголовок панели: −1 px; отступы панели
  content_margin 14/12 → **10/8**.

## 3. Палитры не срезаются — перенос строк
- Ряды чипов «Камуфляж» и «Скин» → WrapContainer (перенос на 2-ю строку
  при нехватке ширины), то же для рамок «Стандарт/Новобранец/…»;
- Свотчи «Кожа» → 2 ряда по 4–5 шт вместо одного длинного;
- Подпись «Аватар: на экране…» (моб.) оставить.

## Проверка
Гейт ?uitest=1 на 914×570 и на скриншотном окне из жалобы (~1860×1290):
скроллбара по центру нет; Кожа — 2 ряда, все свотчи видны; Скин/Камуфляж
переносятся; ни одна колонка не прокручивается (всё видно целиком).
