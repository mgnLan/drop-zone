# ПАК «BP SEASON v1» — запуск Battle Pass (решение создателя: переход к бета/проду)

Контекст: разработка фич заморожена, идём в бета-тест/прод. Этот пак —
закрываемый хвост Battle Pass + чек-лист релиза. Порядок важен.

## 1. Free-финал: «Призрак» → арендный токен 30 дней (решенО создателем)
Сейчас free-финал 50 ур. выдаёт мифика «Призрак» (hid 11) НАВСЕГДА —
обесценивает premium. Заменить на арендный токен с отложенной активацией.

Новый вид награды/предмета «токен аренды» (общая механика под будущие
карты аренды из сундуков и кассы):
- Профиль: `hero_tokens: [{hid, days, activated}]` (сервер + клиент,
  сохранение в save/load рядом с hero_rentals).
- Получение: `BP_TABLE_FREE[50] = {"kind": "hero_token", "hid": 11,
  "days": 30, "name": "Призрак — аренда 30 дн (активация в любой момент)"}`.
  В `_bp_claim` ветка "hero_token": append в hero_tokens, НЕ трогая
  hero_rentals (часы НЕ идут с получения).
- Активация: экран «Герои» — у владельца токена кнопка «Активировать»
  на карточке «Призрак»: переносит {hid, days} в hero_rentals
  (`max(now, остаток) + days`, текущая формула ~11240) и удаляет токен.
  Токенов несколько — очередь: активировать можно по одному.
- Отображение: в списке героев «Призрак» помечен «аренда готова —
  активируй», до активации не playable.
- Дубликат токена (повторный сезон/награда): не бывает в сезоне 1 —
  assert в лог, не крешить.

## 2. Premium-пропуск: товар в консоли VK
- Создать товар «Premium Battle Pass — 399 ₽» в консоли приложения
  54822735 (ручной шаг создателя; аналогично пакам монет).
- Прописать item_id в `_buy_bp_pass` (~799–810) — сейчас там заглушка/
  отсутствие реального item. Покупка → серверная верификация
  order_id у ВК (`_on_buybp_result` уже пишет bp_owned — не трогать).
- Кнопка «Premium — 399 руб» уже есть (~11810), снимается блокировка
  вместе с флагом из п.3.

## 3. Запуск сезона
- `BP_SEASON_LIVE := false → true` (1620) — ПОСЛЕДНИЙ шаг пакета,
  когда п.1–2 на тесте и проверены.
- Баланс: 60 дней (SEASON_DAYS, конец 2026-12-02), прогрессия 22 800 XP,
  доход активного ~425 XP/день → проход за ~54 дня. ПЕРВЫЙ СЕЗОН
  ОСТАВЛЯЕМ ЩЕДРЫМ — прогрессию не трогаем. Исправить только устаревшие
  комментарии (~1609–1611: «28 дней/4 недели», «5×50=250» — фактически
  60 дней и 5×45=225).
