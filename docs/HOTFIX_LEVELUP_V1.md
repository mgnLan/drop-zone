# ГОРЯЧИЙ ФИКС «LEVEL-UP v1» — окно уровня: нет выхода, минус сливает старые очки (принято создателем)

Скрины: боевое окно «УРОВЕНЬ 10 — Антон». Два бага.

## Баг 1 — окно нельзя закрыть (софтлок UX)
`_show_levelup` (origin/main game/scripts/arena3d.gd ~4816–4926) создаёт
только кнопку «ПОДТВЕРДИТЬ» (~4922). Ни крестика, ни Esc, клик мимо панели
не закрывает. Подзаголовок «нераспределённые сохранятся» обещает выход
без фиксации, а фактически его нет.
Фикс:
- Переименовать кнопку в «ГОТОВО» (подтверждения распределения не требуется
  — очки применяются в `_lvl_add` сразу);
- Кнопка «×» в правом верхнем углу панели = то же закрытие;
- Esc закрывает окно (gui_input на wrap или в общем обработчике клавиш:
  если _lvl_open — закрыть, иначе обычная логика);
- Закрытие = тот же путь, что `_lvl_confirm` (queue_free wrap, _lvl_open=false,
  _refresh_fighter_panel, _refresh_squad), без лога «навыки обновлены».

## Баг 2 — «−» разрешает перекидку ранее вложенных очков (регресс)
`_lvl_add` (~4796–4804): при d<0 проверяется только stats[k] > 0 —
можно снять очки, вложенные на прошлых уровнях, и направить в другой скилл.
Фикс:
- В `_show_levelup` снять снапшот base_stats = f.stats.duplicate() при
  открытии окна;
- Минус разрешён только пока f.stats[k] > base_stats[k]; при достижении
  базы — minus.disabled = true (пересчёт состояний минусов после каждого
  +/-, а не только текущей строки);
- Плюс — без изменений;
- Пересборка окна при покупке таланта (~4908–4913): снапшот пересоздавать
  в момент пересборки (таланты stats не меняют — дрейфа базы не будет);
- Окно из лобби (экран отряда) — тот же механизм, общий код.

## Проверка
- В бою поднять уровень → окно: Esc закрывает, «×» закрывает, «ГОТОВО»
  закрывает; нераспределённые очки сохранились (строка «Свободно очков»
  после повторного открытия);
- Вложить очко в Силу → минус у Силы активен; довести до базы → минус
  гаснет; минусы у всех стат, равных базе, изначально гаснут;
- Попытка перекинуть очки между скиллами невозможна (снять можно только
  то, что вложено в текущей сессии окна);
- Скрины, FIXLOG, заливка на ТЕСТ (прод не трогать).
