# ГОРЯЧИЙ ФИКС «МАГАЗИН-ВЛАДЕНИЕ v1» — не отмечены купленные косметика (принято создателем)

Скрин: раздел с рамками — владелец получил много рамок через сундуки,
в магазине они не отмечены как полученные, выбрать/понять владение нельзя.

## Причина (проверено по коду)
Данные в порядке: сундук ставит владение через `_owned_grant()`
(~arena3d.gd:12009, owned_frames/owned_colors). Ломается отрисовка:
сетка «РАМКИ» (~12392–12444) и «ЦВЕТА НИКА» (~12477–12512) показывает
«Куплено» ТОЛЬКО если товар есть в SHOP_ITEMS (~1670 — там только рамки
idx 1–2 и цвета idx 1–2). Всё, что падает только из сундуков (рамки 3–8,
цвета 3–8), попадает в молчаливую ветку — пустая ячейка под названием.
Дополнительно: тировые рамки 9–11 (Ветеран/Элита/Легенда) в сетку не
входят вовсе (`for fi in 9`).

## Фикс
1. РАМКИ: ветка `fsi < 0 and fi != 0` → если `_shop_owned("frame", fi)`:
   Label «Куплено» (тот же стиль: 11 px, #73e68c, по центру); иначе Label
   «В сундуках» (11 px, #9aa7bd, тултип «Выпадает из сундуков удачи»).
2. ЦВЕТА НИКА: аналогично в ветке `csi < 0 and ci != 0`.
3. Расширить сетку рамок до 12 (`for fi in 12`): тировые 9–11 —
   owned → «Куплено», не owned → «Тир N ур.» (11 px #9aa7bd, тултип
   «Награда за вход в тир, N ур.»). Цвета сетки/колонок сохранить
   (5 на десктопе, 3 на мобилке — 12 ячеек лягут 5+5+2).
4. Консистентность имён: SHOP_ITEMS «Рамка «Неон»» → «Рамка «Неоновая»»
   (FRAME_NAMES: «Неоновая») — одна строка, (~1670).
5. Поведение покупки не менять.
6. ЭКИПИРОВКА ИЗ МАГАЗИНА (одобрено создателем): на владенных ячейках
   под «Куплено» — кнопка «Надеть» (мини-стиль ценовой кнопки: высота 24,
   шрифт 11, стиль «Перелив» normal) → `_shop_equip(kind, idx)` +
   пересборка экрана. Надетая ячейка: вместо кнопки — метка «Надето»
   (11 px акцент #28d8ff). Хелперы готовые: `_shop_equipped` /
   `_shop_equip` (~1683–1691). Работает для сундучных и тировых рамок
   и для цветов ника. Выбор рамки общий на профиль (как в отряде) —
   поведение идентично селектору отряда.

## Проверка
- ?uitest=1: экран «Сундуки/Рамки и цвета» — у владельца все полученные
  рамки (включая сундучные 3–8 и тировые 9–11) помечены «Куплено» с
  кнопкой «Надеть»; нажал «Надеть» → метка сменилась на «Надето», выбор
  виден в селекторе отряда и профиле; невладение → «В сундуках» /
  «Тир N ур.»; кнопки покупки на месте у не купленных 1–2.
- --testplay зелёный (COSMETIC_TEST).
- Скрины, FIXLOG, коммит, заливка на ТЕСТ (прод не трогать).
