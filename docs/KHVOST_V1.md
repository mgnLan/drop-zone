## 4. ЭКОНОМИКА v1 (цифры утверждены создателем)
### 4.1. Реген Медсанчасти (сейчас слишком быстрый)
`_med_full_minutes`: `10 + 0.5·lvl` → **`40 + 2·lvl`**.
(ур. 1 — 42 мин, ур. 7 — 54 мин, ур. 25 — 90 мин, ур. 50 — 140 мин на полное HP)
ВИП ×2 сохранить. Подпись «ранен (~N мин)» пересчитается сама.

### 4.2. XP по режимам (кривая НЕ трогается)
Сейчас: убийство +50, попадание +25+урон — в 4×4 это в 4–16 раз больше
каналов XP при той же кривой. Нормировать:
- убийство: 1×1 → +50, 2×2 → +30, 4×4 и Арена лидеров → +18;
- попадание: 1×1 → +25+урон, 2×2 → +15+урон, 4×4/арена → +10+урон;
- +100 за бой и прочие источники — без изменений.

### 4.3. Монеты за бой (убрать множители режимов)
Вместо `(2 + kills) × множитель`:
- 1×1: `3 + 0.5·kills`
- 2×2: `5 + kills`
- 4×4: `10 + 2·kills`
- Арена лидеров: `15 + 2·kills`
- Жнец: `25 + 2·kills`
- Обучение ×2 — сохранить; ставка букмекера ×2/×0.5 → **×1.5/×0.5**;
- PvP 30/10 и +100 первой победы дня — без изменений.

### 4.4. Цены услуг ×3
- Лечение: 50 → **150** монет (осколки 10 → 30)
- Реанимация: 100 → **300** монет (осколки 15 → 45)
- Наём бойца: 350 → **1050** монет
- Сброс талантов: 600 → **1800**; Переподготовка статов: 600 → **1800**
- «Доктор за ролик» — проценты не менять.

### 4.5. Паки монет — объёмы ×3 (цены в ₽ те же)
- 29 ₽: 100 → **300** монет
- 99 ₽: 500 → **1500** монет
- 199 ₽: 1200 → **3600** монет
- id товаров, цены в консоли ВК и CASH_PRICES (₽) — не менять,
  меняется только объём начисления.

### Проверка экономики
Тестовый бой 1×1 (2 убийства) и 4×4 (8 убийств): в логе доход = 4 и 26
монет, XP за убийства = 50/18. Реген: `_med_full_minutes(7)` = 54.
