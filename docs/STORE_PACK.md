## Что сделать в консоли (по чек-листу «Обязательные настройки»)
1. Размещение → Состояние «Включено» — включить.
2. Размещение → URL для запуска: https://podvezu.online/dropzone
3. Оформление → загрузить иконки/сниппет/скриншоты из docs/store/.
4. Монетизация → регистрация в кабинете выплат (приложение уже в кабинете,
   ждём активации).
