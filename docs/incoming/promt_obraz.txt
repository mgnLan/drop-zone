# ПРОМТ: СОЗДАНИЕ ОБРАЗА ПЕРСОНАЖА И УЛУЧШЕНИЕ UI

## ЧАСТЬ 1: ВИЗУАЛЬНЫЙ ОБРАЗ ПЕРСОНАЖА

Проанализируй текущий код игры Dropzone Alpha и предложи улучшения для визуального стиля персонажей.

### Текущее состояние:
- Персонажи рисуются процедурно через Canvas (drawRoundedHuman)
- Есть 4 цвета кожи, 2 пола, 6 командных цветов
- Оружие отображается как прямоугольник
- Шлемы как простые формы

### Задачи:

**1.1. Улучшение детализации персонажей:**
- Предложи более детализированные спрайты (можно через SVG или улучшенный Canvas)
- Добавь варианты причесок (короткие, длинные, ирокез, лысый)
- Добавь варианты одежды (тактическая, гражданская, бронированная)
- Добавь аксессуары (очки, шрамы, татуировки)
- Улучши отображение оружия (разные типы: пистолет, винтовка, нож)

**1.2. Анимации:**
- Анимация дыхания (уже есть, но улучшить)
- Анимация ходьбы (более плавная)
- Анимация стрельбы (отдача, вспышка)
- Анимация получения урона (покраснение, наклон)
- Анимация смерти (падение)

**1.3. Визуальные эффекты:**
- Тени под персонажами (уже есть, но улучшить)
- Свечение при критическом ударе
- Эффект невидимости/маскировки
- Индикаторы состояния (горение, отравление)

**1.4. Кастомизация:**
Предложи систему кастомизации как на скриншоте:
- Выбор ника (текстовое поле)
- Выбор пола (Мужчина/Женщина)
- Выбор цвета кожи (Светлый/Смуглый/Тёмный/Фарфоровый)
- Выбор цвета ника (Белый/Красный/Золотой)
- Выбор рамки аватара (Стандарт/Неоновая/Золотая)
- Выбор аватара (пресеты или загрузка фото)

## ЧАСТЬ 2: УЛУЧШЕНИЕ UI ТЕКСТОВ И РАМОК

Проанализируй текущий CSS и предложи улучшения для интерфейса.

### Текущее состояние:
- Используется glassmorphism (полупрозрачные панели с blur)
- Золотой акцентный цвет (#ffd700)
- Шрифт Inter
- Кнопки с градиентами и hover-эффектами

### Задачи:

**2.1. Улучшение текстовых элементов:**

Предложи улучшения для:
- Заголовков (h1, h2, h3) — размеры, тени, анимации
- Обычного текста — читаемость, контраст
- Цифр (HP, AP, уровень) — выделение, цвета
- Лог событий — форматирование, цвета для разных типов событий
- Названий предметов — иконки + текст

**2.2. Улучшение рамок и карточек:**

Предложи улучшения для:
- Карточек персонажей (card) — тени, градиенты, анимации при наведении
- Кнопок (btn) — размеры, отступы, состояния (hover, active, disabled)
- Панелей (sidePanel, bottomBar) — позиционирование, прозрачность
- Popup окон — анимации открытия/закрытия, прокрутка
- HP баров — градиенты, анимации изменения
- Полей ввода (input) — фокус, валидация

**2.3. Адаптивность:**

Предложи улучшения для:
- Мобильных устройств (<700px) — скрытие боковой панели, увеличение кнопок
- Планшетов (700-900px) — уменьшение панелей
- Десктопов (>900px) — полная версия

**2.4. Анимации и переходы:**

Предложи добавить:
- Плавное появление элементов (fadeIn, slideIn)
- Анимации при наведении (hover)
- Анимации при клике (active, ripple effect)
- Переходы между экранами
- Анимации изменения значений (счетчики HP, AP)
