# ПРОМТ: РЕДИЗАЙН ЛОББИ (ЭКРАН ПОСЛЕ ЛОГИНА) + МОБИЛЬНАЯ ВЕРСИЯ

## КОНТЕКСТ

Игра: DROP ZONE ROYAL BATTLE — браузерная пошаговая тактика (киберпанк-арена, красные vs зелёные).
Стек: HTML + CSS + JS. Скриншоты текущего состояния приложены (ПК и мобильные).

## ТЕКУЩИЕ ПРОБЛЕМЫ (ПО СКРИНШОТАМ)

ПК (скрин 1):
1. Меню — длинный столбец одинаковых кнопок, низ НЕ ВЛЕЗАЕТ в экран
2. Нет иконок и визуальной иерархии кнопок
3. Чат слева слишком широкий (~460px), нет кнопки свернуть
4. Лого плоское, заставка не растянута на весь экран

Мобильные (скрины 2-4):
5. Название игры — простая надпись, нужен современный 3D/анимированный вид
6. Заставка квадратная по центру — растянуть на весь экран
7. Кнопки блёклые, непонятно куда нажимать

## ЗАДАЧА 1: НОВАЯ СХЕМА ЛОББИ (ПК)

Сделай сетку из 3 колонок вместо столбца:

┌──────────────────────────────────────────────┐
│ ЛОГО 3D ✨              [][🪙][][💀] чипы │
├───────────────┬──────────────┬───────────────┤
│ ⚔️ БОЙ        │ 🗂️ УПРАВЛ.  │ 📋 ЗАДАНИЯ    │
│ 🎯 1×1 глав.  │ 👥 Отряд     │ 💀 0/5 +50🪙  │
│ 🔒 2×2 прогр. │ 🛒 Магазин   │ 📦 0/3 +40🪙  │
│ 🔒 4×4 прогр. │ 🎨 Профиль   │ 🏆 0/1 +75🪙  │
│               │ ⚙️ Настройки │               │
├───────────────┴──────────────┴───────────────┤
│ [💬 чат 280px]  или  [✉][✉][✉] когда свёрнут │
└──────────────────────────────────────────────┘

Требования к кнопкам-карточкам:
- Иконка + заголовок + подзаголовок (2 строки), компактно
- Скошенные углы (clip-path), неоновая рамка
- Переливающийся блик (shimmer-анимация) и свечение при hover
- Главная кнопка боя — красно-оранжевый градиент
- Заблокированные режимы — замок + полоса прогресса побед (0/3, 0/25)
- Верхняя панель: лого слева, чипы игрока справа (ник, монеты, победы, убийства)

## ЗАДАЧА 2: ЧАТ СО СВОРАЧИВАНИЕМ И 3 КОНВЕРТАМИ

- Ширина чата 280px (сжать по горизонтали)
- Кнопка «—» в шапке чата для сворачивания
- В СВЁРНУТОМ виде вместо чата — 3 маленьких конверта-письма в ряд:
  • Общий чат — голубой неоновый конверт, иконка 🌐
  • Чат комнаты — розово-красный конверт, иконка ⚔️
  • Чат с кланом — золотой конверт, иконка 🛡️
- Конверт рисуется на CSS (прямоугольник + треугольный клапан)
- Если пришло сообщение в свёрнутом состоянии — на конверте красный бейдж с числом
- Клик по конверту разворачивает чат на нужной вкладке
- Напиши JS-функцию window.chatNotify(type), которую будет вызывать игровой код

## ЗАДАЧА 3: АДАПТИВНОСТЬ (МЕНЮ ДОЛЖНО ВЛЕЗАТЬ ВСЕГДА)

- Основная зона лобби: overflow-y:auto + компактные карточки
- @media (max-width:1100px): 2 колонки, задания уходят вниз
- @media (max-width:768px): 1 колонка, чипы в шапке мельче, чат — шторка снизу
- @media (max-height:640px): уменьшить отступы и лого
- Ничего не обрезается ни на 1366×768, ни на 1920×1080, ни на телефоне

## ЗАДАЧА 4: МОБИЛЬНАЯ ВЕРСИЯ И ЗАСТАВКА

- Лого «DROP ZONE» — объёмное 3D: многослойный text-shadow, градиент внутри букв (background-clip:text), неоновое свечение, лёгкая анимация парения/мерцания. Класс .logo3d переиспользовать и на заставке, и в лобби
- Подзаголовок «ROYAL BATTLE» + строка описания — в современном виде (неон, letter-spacing, светящаяся линия)
- Заставка (фон) — position:fixed; inset:0; background:center/cover — растянута на ВЕСЬ экран на ПК и мобильных (не квадратом!)
- Все кнопки мобильные: высота 48-56px, шрифт 15-16px, свечение/градиент, эффект нажатия scale(.97)
