# ПРОМТ: РЕДИЗАЙН ЭКРАНА ВХОДА/РЕГИСТРАЦИИ DROP ZONE

## КОНТЕКСТ

Игра: Drop Zone Royal Battle (постапокалиптическая тактическая арена, киберпанк-стиль 2026)
Стек: HTML + CSS (один файл)
Текущий экран: форма входа в аккаунт поверх арт-заставки (красная vs зелёная команда бойцов на арене)

## ТЕКУЩИЕ ПРОБЛЕМЫ (по скриншоту)

1. Форма входа — простая рамка с тонкими кнопками, не в теме игры
2. Название игры "DROP ZONE" находится ВНУТРИ рамки формы — нужно вынести наружу
3. Нет "сияющего" современного дизайна заголовка (стиль 2026: неон, градиенты, свечение)
4. Кнопки тонкие и невыразительные, плохо читаются
5. Размеры не адаптированы: на мобильных форма может не влезть, на десктопе — мелкая
6. Заставка (фон) не выровнена — композиция смещена, персонажи обрезаны по краям
7. Водяной знак и служебные надписи портят вид (учесть отступы под них не нужно, но компоновка должна дышать)

## ЗАДАЧИ

### 1. ЗАГОЛОВОК "DROP ZONE" — ВЫНЕСТИ ИЗ РАМКИ, СВЕРХУ

Сделай заголовок отдельным блоком НАД формой:
- Крупный логотип "DROP ZONE" + подзаголовок "ROYAL BATTLE"
- Стиль 2026: неоновое свечение, градиент (красный #ff2d55 → синий #00e5ff, как команды на арене)
- Эффекты:
  - text-shadow с двойным свечением (внешнее + внутреннее)
  - Анимация мерцания/пульсации (как неон)
  - Лёгкий наклон букв или скос (italic skew -5deg) для динамики
  - Тонкая светящаяся линия-разделитель под заголовком
- Шрифт: жирный, широкий (Russo One / Orbitron / Inter 800)
- Буквы с металлическим градиентом внутри (background-clip: text)

### 2. ФОРМА ВХОДА — ОФОРМИТЬ В ТЕМЕ ИГРЫ

Текущие поля: "Почта", "Пароль (минимум 6 символов)"
Текущие кнопки: "Войти", "Регистрация", "Играть как гость (прогресс только на этом устройстве)"

Требования:
- Контейнер формы: тёмное "тактическое" стекло
  - background: rgba(8,12,20,0.75)
  - backdrop-filter: blur(14px)
  - border: 1px solid rgba(0,229,255,0.35)
  - Скошенные углы (clip-path: polygon) вместо скруглений — милитари-стиль
  - Уголки-насечки по краям (как прицел/HUD) через ::before/::after
- Поля ввода:
  - Высота 52px (мобильный стандарт)
  - Тёмный фон rgba(255,255,255,0.06), рамка 1px rgba(255,255,255,0.15)
  - При фокусе: рамка загорается неоном (красный или синий), тень-свечение
  - Иконки слева (✉ для почты, 🔒 для пароля)
  - Placeholder светло-серый, читаемый
- Кнопки (все минимум 52px высотой, полноразмерные):
  - "ВОЙТИ" — главная: градиент красный→оранжевый, свечение, hover: ярче + подъём
  - "РЕГИСТРАЦИЯ" — вторичная: прозрачная с неоновой синей рамкой
  - "Играть как гость..." — третичная: текст-ссылка с иконкой 👤, мелкий шрифт, но зона тапа 48px
- Расстояние между кнопками 12px
- Мелкий текст-подсказка под формой: "Прогресс гостя хранится только на этом устройстве"

### 3. АДАПТИВНОСТЬ (WEB + МОБИЛЬНЫЕ)

Десктоп (>1024px):
- Форма по центру справа или по центру, ширина 420-460px
- Заголовок сверху по центру, размер clamp(48px, 6vw, 84px)

Планшет (768-1024px):
- Форма 400px, заголовок clamp(40px, 5vw, 64px)

Мобильные (<768px):
- Форма: width: calc(100% - 32px), max-width 420px
- Заголовок: clamp(32px, 9vw, 56px)
- Кнопки 52px высотой, шрифт 16px+
- Поля 52px, шрифт 16px (иначе iOS зумит при фокусе)
- Вся композиция скроллится вертикально если экран низкий
- Учитывать safe-area (env(safe-area-inset-bottom))

Очень низкие экраны (<640px высота):
- Уменьшить отступы, заголовок 28px, форма компактная

### 4. ЗАСТАВКА (ФОН) — ВЫРОВНЯТЬ

- Фон: object-fit: cover; object-position: center
- Лёгкое затемнение под формой: градиент-оверлей rgba(0,0,0,0.35→0.7) чтобы форма читалась
- Опционально: медленная анимация панорамирования фона (ken burns, 30s)
- Виньетка по краям для кинематографичности

### 5. ДОПОЛНИТЕЛЬНО (стиль 2026)

- Анимация появления: заголовок "въезжает" сверху, форма всплывает снизу (0.5s ease-out)
- Сканирующая линия (scanline) поверх формы — тонкая, полупрозрачная, движется сверху вниз за 4s
- Частицы/искры на фоне (CSS или canvas, 15-20 штук, лёгкие)
- Все анимации отключать при prefers-reduced-motion
