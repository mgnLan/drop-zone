ПРОМТ ДЛЯ KIMI K3: ОПТИМИЗАЦИЯ UI В DROPZONE ALPHA
КОНТЕКСТ
Я разрабатываю браузерную тактическую пошаговую игру Dropzone Alpha (HTML5 Canvas + JavaScript, один файл ~2000 строк). Игра в стиле Fallout Tactics/XCOM с изометрической картой, пошаговыми боями, инвентарём и системой уровней.
Текущая проблема: UI-панели слишком крупные и съедают игровое поле, особенно на мобильных устройствах (70% игроков ВК с телефонов).
📸 АНАЛИЗ СКРИНШОТА (текущее состояние)
На скриншоте видны следующие проблемы:
1. Левая панель (отряд) — слишком большая
Блок активного бойца "Сокол" занимает ~25% высоты экрана
Аватары бойцов крупные (~60px)
HP бары широкие
Дублирование информации (HP в большом блоке и в списке)
2. Правая панель (статус) — перегружена
4 строки текста + 4 кнопки в 2 ряда
Панель широкая (~380px)
Занимает ~20% ширины экрана
3. Нижняя панель (логи) — нормально, но вкладки лишние
"Чат Арены" и "Чат комнаты" в оффлайн-режиме бесполезны
Надпись "Чат появится в онлайн-режиме..." — заглушка
4. Общие проблемы
Нет мобильной адаптации
Панели почти чёрные (не видно карту за ними)
Кнопки мелкие для тапа на телефоне
🎯 ЗАДАЧИ ДЛЯ KIMI K3
ЗАДАЧА 1: УМЕНЬШИТЬ ПАНЕЛИ НА 30-40%
Напиши CSS-код для следующих изменений:
Левая панель (отряд):
Ширина: 280px → 200px
Блок активного бойца: высота 180px → 120px
Аватары в списке: 60px → 40px
HP бары: 8px → 4px
Шрифт: 14px → 12px
Убрать дублирование HP (оставить только в списке)
Правая панель (статус):
Ширина: 380px → 260px
Сократить текст: "В руках: Дробовик [патр. 6]" → "🔫 Дробовик [6]"
Объединить строки: "Ур. 1 · Опыт 0/100 · Убийств: 0" → одна строка с иконками
Кнопки: 4 кнопки в 2 ряда → 4 иконки в 1 ряд (🎒 🔪 ⭐)
Шрифт: 14px → 12px
Нижняя панель (логи):
Высота: 280px → 200px
Убрать вкладки "Чат Арены" и "Чат комнаты" (если нет онлайна)
Оставить только "Логи битвы" + поле ввода чата
Шрифт: 13px → 11px
Общие изменения:
Прозрачность панелей: background: rgba(0,0,0,0.6) вместо rgba(0,0,0,0.9)
Добавить backdrop-filter: blur(8px) — будет видно карту за панелями
Границы арены: 4px → 2px (неоновые линии)
