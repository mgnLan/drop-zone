# АУДИТ DROP ZONE — Royal Battle (Godot-версия v6.6)
Дата: 28.08.2026. Метод: построчный аудит `game/scripts/arena3d.gd` (~3140 строк), `game/data/items.json`, прогоны `--testbots` / `--testplay`. Чек-лист адаптирован под Godot-версию (пункты HTML-прототипа отмечены N/A или «перенесено»).

## ✅ ЧТО РАБОТАЕТ ОТЛИЧНО

**Геймплей-ядро**
- Пошаговая система: ход игрока → ходы ботов с задержками (0.25–0.5 с), восстановление ОД, пропуск погибших.
- Движение по BFS-пути с анимацией Run_Gun, поворотом в сторону шага и звуком на каждой клетке.
- Прицеливание: луч + плашка шанса попадания (зелёный/жёлтый/красный, «ДАЛЕКО», «НЕТ ЛИНИИ ОГНЯ») — считается той же математикой, что и выстрел.
- Укрытия: лёгкие −15% за каждое на линии, тяжёлые и дома блокируют LOS (Брезенхэм). Шанс ограничен 25–95%.
- AoE с friendly fire, разрушение укрытий взрывами (тяжёлые — 3 взрыва, лёгкие — 2), освобождение клеток и LOS после разрушения.
- Входимые дома: дверь, запрет стрельбы снаружи↔внутри, бой внутри одного дома, полупрозрачность дома с бойцом внутри.
- Огонь (Молотов/зажигательная): 3 раунда, −8 HP стоящим, боты обходят горящие клетки, в домах не горит.
- Туман войны — честный и для игрока, и для ботов (обзор + LOS).
- Прогрессия: +50 XP за попадание (ИНТ +10%/очко), порог 100·1.2^(lvl−1), +5 очков за уровень, полное лечение, крит ×1.5 от УДАЧИ (+3%/очко). Прогресс сохраняется в профиль между матчами; меню отряда = полный респек.
- Экипировка: 3 слота брони с защитой и весом, носимый вес, надетое не занимает рюкзак, drag&drop, одноразовые расходники, нож всегда в инвентаре.
- 16 стволов + нож (items.json), 12 брони, аптечка и батарея AP. Ящики со скрытым содержимым (оружие всегда, броня 60%, расходники).

**Интерфейс и презентация**
- Меню с арт-фоном и неоновым логотипом, рамки, hover-прожатие кнопок.
- Режимы 1×1 / 2×2 / 4×4 с соразмерными картами (22/28/40).
- Ростер с портретами (6 пресетов + свой аватар), чат-панель (Логи/Арена/Комната), рюкзак под портретом.
- Камера: орбита ПКМ, зум колесом, тряска при взрывах.
- Эффекты: взрыв (шар + свет + частицы + тряска), смерть (звук + красный всплеск + падение корпуса), levelup-арпеджио.

**Техника**
- Лог ограничен 60 записями. Ресурсы эффектов освобождаются (queue_free по таймерам/tween).
- Автотесты: `--testbots` (полный бой с ботами), `--testplay` (ящик+инвентарь), `--testmenu`, `--shot` — все зелёные на v6.6.
- Деплой-конвейер: экспорт Web → OpenServer → FTP reg.ru одной командой.

## ⚠️ ТРЕБУЕТ УЛУЧШЕНИЯ

1. **Нет подсказки стоимости ОД на клетках** (в референсе цифры на подсвеченных клетках). У нас зона досягаемости есть, цены хода — нет.
2. **Нет HP-баров над бойцами** — HP виден только в ростере слева и панели выбранного бойца.
3. **Нет визуала попадания по живой цели** — кровь/всплеск есть только при смерти; обычное попадание = только звук и строка лога.
4. **Боты не штурмуют дома**: если игрок засел внутри, боты его не видят (LOS) и идут к центру. Нужен захват двери/вход в дом как цель.
5. **Боты не перезаряжаются упреждающе** и не пользуются ящиками/аптечками — тактически примитивны.
6. **Инвентарь без лимита слотов** — ограничение только по весу (в референсе 8 слотов). Для баланса шоу-режима, возможно, нужен лимит клеток рюкзака.
7. **Патроны не суммируются** при подборе (в референсе объединение одинаковых патронов) — у нас у каждого ствола свой магазин, дубликат ствола = отдельный предмет.
8. **Экран конца боя минимален**: нет таблицы статистики (Lv/Kills всех бойцов), только победа/поражение + кнопка «В лобби».
9. **Вигнетки нет**; декоративная полировка кадра (пост-эффекты) не завезена.
10. **Настройки графики** переключают пресеты, но без предпросмотра; нет ползунка громкости (только вкл/выкл звук).
11. **Меню «Отряд»**: респек бесплатный и безграничный — убивает ценность решений; позже стоит платить валютой за респек (монетизация).

## ❌ КРИТИЧЕСКИЕ БАГИ

1. **Мобильный ввод отсутствует полностью** — только мышь (ЛКМ/ПКМ/колесо) и клавиатура. Для ВК-миниаппа, где ~70% трафика мобильный, это блокер публикации: нужны тач-события (тап = ЛКМ, свайп = орбита, щипок = зум) и адаптивный UI (сейчас панели на жёстких координатах 1080/470 и т.п.).
2. **UI не адаптивен к разрешению окна**: координаты панелей захардкожены под ~1280×720 (кнопка «Конец хода» на x=1080, лог на y=680). На узких/высоких окнах элементы уедут — нужны анкеры.
3. **Смерть от огня в ход противника не обновляет HUD мгновенно** в момент тика — обновление происходит, но если огонь добил последнего бойца, экран конца боя появляется только после `_check_end` внутри `_apply_damage` — прогон это покрывает частично; стоит добавить тест «добивание огнём».
4. **Расходник в руках при смерти не выпадает** — лут погибшего пропадает. Для королевской битвы ожидаемо выпадение рюкзака на клетку смерти (жанровый стандарт, в референсе тоже нет — но у нас ящики-ориентиры, трупный лут усилит петлю).

## 💡 ПРЕДЛОЖЕНИЯ ПО УЛУЧШЕНИЮ

- Подсветка пути к клетке под курсором (пунктир + цена в ОД) — следующий шаг полировки.
- Взрываемые бочки из референса (есть в наборе моделей) — цепные взрывы, тактическая глубина.
- Золотые частицы при крите (референс) + звук крита.
- Таблица итогов боя: Lv/Kills/урон по каждому бойцу, MVP — усилит желание реванша и скриншоты для группы ВК.
- Достижения/заслуги → открытие слотов бойцов 2–4 (механика уже задокументирована в меню).
- Сохранение реплея боя (лог уже есть) → «лучшие моменты» для контента группы.
- Версионный cache-bust при деплое (?v= в index.html), чтобы не ловить Ctrl+F5.

## 📈 ПРИОРИТЕТЫ ИСПРАВЛЕНИЙ

1. **Тач-управление + адаптивный UI (анкеры)** — без этого ВК-публикация бессмысленна.
2. **Боты штурмуют дома** — иначе «сидеть в доме» = бессмертие, ломает баланс.
3. **HP-бары над бойцами + стоимость ОД на клетках** — читаемость боя, дёшево по трудозатратам.
4. **Экран итогов со статистикой** — удержание и контент для соцсетей.
5. Кровь при попадании, бочки, трупный лут.

## ОБЩАЯ ОЦЕНКА ГОТОВНОСТИ: 6.5 / 10

Ядро боя, прогрессия, лут, дома, огонь и разрушения — работают и покрыты автотестами; визуально и звуково игра уже «не стыдная». До релиза в ВК не хватает главного: мобильного ввода и адаптивного UI (−2), пары геймплейных дыр (бессмертие в доме, нет итоговой таблицы) (−1), и мелкой полировки (−0.5).
