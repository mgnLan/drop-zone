# КНОПКИ «ПЕРЕЛИВ v2» — готовые ассеты + спецификация (от дизайнера)

Ассеты: `game/assets/ui/buttons/` (коммит с ассетами — см. git log).
Пиксель-точный рендер по палитре игры, 9-slice, прозрачный фон у shine-кадров.

## Файлы
- `btn_bg_normal.png` 512×128 — фон: вертикальный градиент #1b2233→#0c101c,
  спокойная рамка #2b3a55 2 px, верхний блик. Обычное состояние.
- `btn_bg_hover.png` 512×128 — фон светлее (#232c42→#101627), рамка циан

- `btn_bg_priority.png` 512×128 — диагональный градиент #ff3c6e→#ff7a45,

- `btn_shine_00.png` … `btn_shine_11.png` 512×128 ×12 — анимация перелива:
  ободок тонирован бегущим градиентом роза→циан→золото, по нему бежит

  звёздочка дважды вспыхивает. Цикл 2.4 c при 5 fps. Прозрачный фон —
  накладывать ПОВЕРХ фона кнопки.

## 9-slice
StyleBoxTexture, texture margins: left/right **24**, top/bottom **20**
(радиус скругления 20). Минимальная высота кнопки 44 px — масштабирование
9-slice держит углы.

## Как собрать в Godot (4.7)
1. Обычная кнопка: Button с Theme Override → Styles → normal/hover/pressed/
   disabled = StyleBoxTexture на соответствующем фоне (pressed — тот же
   normal с modulate 0.85).
2. Перелив: поверх фона TextureRect (stretch, весь rect кнопки), текстуры —
   12 кадров btn_shine_XX.png, кадры переключаются в `_process` по
   `Time.get_ticks_msec() / 200 % 12` (каждые 200 мс). Мышь IGNORE —
   не перехватывать клики.
3. Состояния: hover → btn_bg_hover (+shine не гасить); disabled → фон
   normal, modulate #6b7688, shine скрыт; «Выбрано» → заливка #28d8ff33
   поверх + бордер #28d8ff, shine скрыт.
4. Текст: белый #f2f6ff, для priority — белый жирный; autoshrink ВЫКЛЮЧЕН,
   min_size по тексту (обрезание цифр больше не повторяется).
5. Кадры shine — общие для всех кнопок: грузить 12 текстур один раз,
   раздавать ссылку (не дублировать загрузку на каждую кнопку).
