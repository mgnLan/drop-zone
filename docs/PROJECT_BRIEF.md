# Drop Zone — Project Brief
> Рабочее название: **Drop Zone**. Дата фиксации: 2026-08-25. Статус: пре-продакшн.

## 1. Концепция
Пошаговая тактическая онлайн-игра (2–8 игроков на карте) по мотивам механик Total Influence,
но со **своим сеттингом и историей** (плагиат исключён: свои имена, арт, тексты, мир).

**Режимы:**
- Battle Royale соло (2–8 игроков)
- Пары (2×2×2×2)
- Командные 3×3 и 4×4

**Ядро геймплея:** пошаговые бои, очки действия (AP), укрытия (включая лёгкие типа кустов),
ландшафт, экипировка, лут, прокачка персонажа.

## 2. Платформы
- VK Mini App
- MAX Mini App (по готовности адаптации)
- Standalone-браузер
- Единый профиль и сохранения между платформами (VK ID / MAX ID / гость)

## 3. Стек (решено)
| Слой | Технология |
|---|---|
| Клиент (графика, ввод) | **Godot 4** (GDScript), web-экспорт |
| Сервер боёв | **Node.js** (WebSocket, авторитетная симуляция) |
| Аккаунты, сохранения, платежи | **Laravel** на reg.ru |
| Арт на старте | **Покупные/бесплатные ассет-паки**, кастом — точечно позже |

## 4. Сеттинг (решено 2026-08-25)
**Аренный спорт будущего** — бои как транслируемое телешоу.
Оправдывает все режимы (соло BR, пары, 3×3, 4×4), даёт визуальный стиль:
арены, неон, камеры, голограммы, трибуны, спонсорские баннеры.
