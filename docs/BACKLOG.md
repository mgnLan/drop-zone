## Контент-паки (после 1.1, по очереди)
### Второй босс для Жнеца (чередовать по кулдаунам 3 дня)
- **«Дирижабль шоу»** (рекоменд.) — летающий, непробиваемый корпус; целься по 2 турелям и гондоле; каждые 3 раунда бомбит 3 случайные клетки.
- «Караул» — 3 связанные турели: пока жива любая — остальные регенят HP.
- «Близнецы» — два босса по 250 HP; разница HP >30% — сильный баффает слабого.

### Второй биом для Арены Лидеров (карта 40)
- **«Ночной порт»** (рекоменд.) — краны через центр, лужи топлива (горят от выстрелов в упор), плотный туман войны.
- «Сталелитейный» — конвейеры двигают бойцов, ковши шлака зонами с кнопками.
