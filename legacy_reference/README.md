# Dropzone Alpha — Isometric Tactical Engine

## Описание
Тактическая пошаговая игра в жанре battle royale с изометрической графикой.
Полностью работает offline в браузере, без npm и внешних зависимостей.

## Файлы
- `dropzone_alpha_standalone.html` — **однофайловая версия** (открывай эту!)
- `dropzone_engine.js` + `dropzone_game.html` — модульная версия для разработки

## Как запустить
### Быстрый старт (рекомендуется)
1. Откройте `dropzone_alpha_standalone.html` в любом браузере
2. Всё работает сразу, ничего настраивать не нужно

### Для разработки
1. Положите `dropzone_engine.js` и `dropzone_game.html` в одну папку
2. Откройте `dropzone_game.html` через локальный сервер (Live Server в VS Code)

## Особенности
- **Изометрия**: ромбовидные тайлы, 3D-стены с гранями, крыши домов
- **Дома**: кирпичные стены, крыша исчезает при входе внутрь
- **Персонажи**: создание (пол, цвет кожи, 6 характеристик), прокачка уровней
- **Оружие**: 15 видов (дальнобойное + метательное), разрушаемые стены
- **AI**: боты с pathfinding (A*), атака, укрытия
- **Звук**: Web Audio API (выстрелы, взрывы, шаги). По умолчанию выключен
- **Zoom**: камера с масштабированием 1.4x

## Управление
- Клик по тайлу — движение
- Клик по врагу — атака
- Клик по ящику — открытие
- Кнопки: INVENTORY, EQUIP, WEAPON, END TURN
- SOUND: ON/OFF — переключение звука

## Технологии
- Чистый JavaScript (ES6+)
- HTML5 Canvas 2D
- Web Audio API
- Без фреймворков и библиотек
